# Отдельный Диадок — 0.2.0-preview.3

Этот адаптер нужен, когда Диадок работает отдельно от 1С. Он обращается непосредственно к официальному API Диадока. HTTP-сервис kyvirok в базе для этих функций не нужен. Пароль 1С и вход в браузере не дают авторизацию API.

Реализованы чтение входящих/исходящих документов, поиск по номеру, датам документа, типам, статусам, контрагентам и подразделениям; получение статуса отдельного документа; PDF **уже существующего в Диадоке** документа после подтверждения. Это не создание новой УПД в 1С и не генерация XML из реализации.

Добавлен импорт **уже выгруженного XML** УПД/счёта-фактуры в неподписанный черновик Диадока. Автоматическое получение XML из 1С, подписание, отправка и прямой адаптер СБИС/Saby ещё не реализованы. Профили `1c-edo`, `diadok`, `sbis` серверного адаптера сохранены отдельно. Наличие профиля не означает установленную интеграцию. Тесты выполняются с имитацией API; совместимость с настоящим кабинетом пока не подтверждена. Подробная установка, браузерный вход по почте/коду и форма отчёта — [AGENT-GUIDE.md](AGENT-GUIDE.md).

## Подключение

1. Администратор проверяет право использования API и права пользователя к нужному ящику. Условия определяет оператор. Не выпускайте ключи и не покупайте доступ автоматически.
2. В каталоге настроек kyvirok (рядом с `config.json`) создайте `edo-policy.json` по `edo-policy.example.json`. Замените демонстрационный GUID на `BoxIdGuid` существующего ящика. Название подключения — строчные латинские буквы, цифры и `_`, например `office_diadok`. Разрешите `documents.read` и, если нужна печать, `document.print`.
3. Получите OAuth `access_token` через согласованное приложение и официальный процесс авторизации Контура. Этот выпуск **не реализует получение/обновление OAuth-токенов**; он использует уже полученный токен. Установка КриптоПро или вход в браузере сами по себе не заменяют этот шаг. Секрет не передавайте в чат, GitHub, JSON с настройками или аргументы командной строки.
4. На Windows запустите локально, указав настоящий каталог настроек:

   ```powershell
   .\setup-edo-windows.ps1 -DataDirectory 'D:\Example\kyvirok-settings' -Account office_diadok
   ```

   Токен вводится скрыто и сохраняется в `edo-office_diadok.dpapi`, зашифрованном для текущего пользователя Windows. Сервер перечитывает его перед запросом. При истечении токена обновите его через оператора и повторите локальный ввод. Пароль 1С хранится отдельно.

   Для другого окружения можно передать токен процессу через `KYVIROK_EDO_OFFICE_DIADOK_TOKEN`. Переменная имеет приоритет над DPAPI. Не сохраняйте её значение в публичном конфиге MCP или диагностике.
5. После изменения правил перезапустите MCP-сервер. `get_edo_connections` показывает настройки; `diagnose_edo_connection` проверяет ящик и реальное чтение документов. Успешный ответ не проверяет подписание и отправку.

HTTP 401 означает проблему с токеном; 402 — подпиской на API; 403 — правами. Сервер не пересылает секреты при перенаправлениях и использует только `https://diadoc-api.kontur.ru`. Адрес API нельзя заменить настройкой.

## Задание агенту сотрудника

- Сначала вызови `get_edo_connections`, затем `diagnose_edo_connection`. Не объявляй весь ЭДО готовым по успешному чтению.
- Используй `list_edo_documents`: `category` — `Incoming`/`Outgoing`, даты в формате `YYYY-MM-DD`. Даты относятся к реквизиту документа, а не ко времени получения. По умолчанию поиск идёт в головном подразделении; для других подразделений задай `departmentIds`.
- Если `mayHaveMore=true`, продолжай с `nextAfterIndexKey`, сохраняя остальные фильтры. Последняя полная страница может потребовать ещё один запрос с пустым результатом. Не выдавай одну страницу или пустую выборку за полный ответ «никто ничего не прислал». Черновики в этот поиск не входят, доступ ограничен правами пользователя.
- Для конкретного статуса — `get_edo_document`. Сохраняй идентификаторы сообщения/документа; номер сам по себе не уникален.
- Для PDF — `preview_edo_print`, покажи документ и затем вызови `apply_reviewed_operation`. Нужна настоящая форма с подтверждением человека. При `pending` вызывай `get_edo_print_status` по возвращённому `requestId` после `retryAfterSeconds`. Срок ожидания — 15 минут в текущем процессе. Не делай частый опрос. Печатная форма скачивается без подписания и отправки.
- Готовый PDF доступен по `localPath` и MCP-ссылке. Каталог файлов задаёт `KYVIROK_1C_ARTIFACTS_DIR`; максимум 20 МБ на PDF и 100 МБ за сеанс. SHA-256 считается по скачанному файлу и проверяется при чтении локального ресурса; это не электронная подпись оператора.

## Импорт XML в черновик без расширения 1С

Первый инструмент для агента — `get_edo_workflow`: он объясняет API- и браузерный пути. Для браузерного пути нужны отдельные инструменты управления браузером и, при входе по коду, разрешённый почтовый инструмент. Вход в кабинет не создаёт API-токен и не даёт доступ к закрытому ключу подписи.

Для API-импорта уполномоченный пользователь добавляет к существующему подключению `draft.create` и выделенный абсолютный `importDirectory`. Пример (демонстрационные значения):

```json
{
  "demo_diadok": {
    "provider": "diadok",
    "boxId": "00000000-0000-0000-0000-000000000000",
    "operations": ["documents.read", "document.print", "draft.create"],
    "importDirectory": "D:\\Example\\kyvirok-import"
  }
}
```

Сохраните остальные подключения, перезапустите MCP-сервер. Пример по умолчанию оставляет импорт выключенным. `preview_edo_draft(account, fileName, recipientBoxId)` читает один файл из разрешённого каталога, проверяет ИНН/КПП сторон по ящикам, показывает полный XML, имя, SHA-256 и получателя. Содержимое XML передаётся оператору **только после** человеческого подтверждения `apply_reviewed_operation`.

После подтверждения сервер распознаёт титул через `DetectDocumentTitles` и вызывает `PostMessage` только с `IsDraft=true`, строгой проверкой и без подписи. Тип и версия определяются оператором, а не выдумываются агентом. Поддержан один однозначно распознанный титул продавца `UniversalTransferDocument`/`Invoice`, XML UTF-8/Windows-1251 с реквизитами сторон `Файл/Документ/СвСчФакт`, до 128 КБ. Форма содержит весь XML и ограничена 24 КБ; большой файл следует проверять и загружать штатным способом через кабинет. Это не XSD-валидатор и не генератор налоговых документов; проверка формата на стороне оператора остаётся обязательной.

Перед запросом создания записывается постоянный локальный журнал в `<каталог результатов>/.edo-drafts`. Он хранит идентификатор операции и квитанцию, без XML и токена. Повтор тех же байтов между теми же ящиками блокируется, в том числе после перезапуска. Сохраняйте журнал при обновлении; не удаляйте записи и не меняйте XML ради обхода защиты. Это защита конкретного импорта, не поиск всех логических дублей по номеру документа.

При `created` сервер получил подтверждение создания черновика. Откройте кабинет и найдите его по `messageId`, номеру, дате и сторонам. При `unknown` (включая HTTP 204, обрыв или неверный ответ) черновик **мог создаться**: не повторяйте запрос; проверьте кабинет. `get_edo_draft_receipt` читает локальную квитанцию и не подтверждает текущий удалённый статус. Сервер не вызывает `SendDraft`, не подписывает, не приглашает контрагентов и не покупает API-доступ.

Дальнейшую подпись и отправку выполняет человек в привычном кабинете, после проверки документа. При кнопке «подписать и отправить» должны быть явно согласованы оба действия. Код для входа из почты не заменяет электронную подпись.

## Что проверить на рабочем месте

Для текущего пути расширение, исходник конфигурации и тестовая база не являются обязательными условиями. Нужно установить фактическую команду штатной выгрузки XML и печатной формы из 1С. Если нужна полностью автоматическая штатная печать внутри базы, её реализация остаётся отдельной задачей под конкретную конфигурацию.

Для подписания/отправки: фактический путь УПД (из 1С XML/PDF или ручной ввод), действующий оператор и API-доступ, выбранная организация, обычный подписант, место хранения ключа и рабочее место подписи, необходимость МЧД. Подписание и отправка должны оставаться отдельными подтверждёнными действиями. Один установленный криптопровайдер этих вопросов не решает.
